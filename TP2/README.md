# TP2 — Filtrage d’images

Solution complète du TP consacré à la convolution, au bruit poivre et sel et aux filtres moyenneur, gaussien et médian.

## Exécution

```powershell
python TP2_Anwar_Ezzirani_G4.py
```

Si `aero1.jpg` est placé dans ce dossier, il sera utilisé automatiquement. En son absence, le programme utilise une image naturelle de démonstration fournie avec Matplotlib afin que le TP reste entièrement reproductible.

Les figures sont enregistrées dans `resultats/` et les mesures de PSNR dans `resultats/mesures_psnr.csv`.
